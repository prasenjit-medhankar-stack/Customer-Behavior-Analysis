# 📌 Project Overview

This project demonstrates a complete data analytics workflow starting from data loading and cleaning to visualization and reporting.

The project includes:
- Loading dataset into Python
- Performing Exploratory Data Analysis (EDA)
- Cleaning and preprocessing data
- Running SQL queries on PostgreSQL
- Building an interactive Power BI dashboard
- Creating analytical reports and presentation slides

The objective of this project is to transform raw customer shopping data into meaningful business insights for better decision-making.

---

# 📂 Dataset Information

### Dataset Name
`customer_shopping_behavior_dataset.csv`

### Dataset Description
The dataset contains customer shopping and transaction-related information including:
- Customer demographics
- Product categories
- Purchase amounts
- Shopping frequency
- Payment methods
- Customer behavior patterns
